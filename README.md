# Personal Site

A dependency-free, early-web-inspired personal page for Harper Austin with
profile links, a visitor counter, and About and Why dialogs.

## Run locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Customize

Edit the profile links and About copy in `index.html`. The email shortcut
currently opens a new email with no recipient so a public address is not exposed.
